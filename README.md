# Nexora Technologies - Final Year Academic Projects & IEEE Research Lab

Nexora Technologies is an engineering capstone and academic project platform offering IEEE-aligned source code, viva coaching, project documentation, resume building, and portfolio development for B.E / B.Tech (CSE, IT, ECE) and postgraduate students.

---

## 🚀 Tech Stack

### Frontend (`/client`)
- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Design Aesthetic**: Light Neumorphic 3D styling with floating interactive badges

### Backend (`/server`)
- **Runtime**: Node.js & Express
- **Database**: MongoDB (Mongoose ODM)
- **Features**:
  - Live Inquiries API (`/api/inquiries`)
  - Dynamic Site Settings & Content Editor API (`/api/settings`)
  - Project Catalog API (`/api/projects`)

---

## 🛠️ Getting Started

### 1. Install Dependencies
```bash
npm run install:all
```

### 2. Run Both Frontend and Backend Concurrently
```bash
npm run dev:all
```
- Frontend runs at: `http://localhost:5173/`
- Backend API runs at: `http://localhost:5000/`

---

## 🎛️ Admin Dashboard
Access the Admin Dashboard directly from the **"Admin"** button in the header or **"Admin Portal"** in the footer to:
- Modify the Hero section headline, subtitle, and services strip in real time.
- Update contact details (Phone, WhatsApp, Email, Campus Address).
- Review and manage incoming student consultation requests.
- Add and delete verified IEEE projects.
